# Calculator

## 💡Project Overview

The Calculator is a responsive web application developed as part of the Frontend Development Internship at CodeAlpha. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division. It features a clean and user-friendly interface with a display screen and interactive buttons. The calculator provides real-time results and is fully responsive, ensuring a smooth experience on desktop, tablet, and mobile devices.

## 🔧Key Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Clear and delete functionality
- Real-time result display
- Responsive design for all screen sizes
- Optional keyboard support
- Clean and intuitive user interface

## 🛠️Technologies Used

- HTML
- CSS
- JavaScript
